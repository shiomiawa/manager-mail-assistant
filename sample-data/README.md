# サンプルデータ

`cs-performance-sample.xlsx` は、週次パフォーマンスレポート（機能1）の動作確認用の**架空データ**です。実在の社員・お客様とは関係ありません。

- 作り直し：`npm run sample-data`（`scripts/generate-sample-data.mjs`。乱数の種を固定しているので毎回同じ内容）
- 期間：2026-08-24〜2026-10-02 の6週間（月〜金）、Week35〜40。最後の Week40（9/28〜10/2）を「今週」として扱う
- シート：「データ」（アプリが読み込む）／「説明」（列の説明）
- 1行＝1日・1人・1チャンネル
- 在籍期間：`02years,05months` の形（2026-10-02時点、3か月〜9年でランダム）。新人のE006だけは3か月に固定。最短はE006（3か月）、最長はE014（9年）
